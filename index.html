40 分钟 奖励 核心

课程概述

掌握奖励函数设计的六大原则：目标一致性、信号密度、尺度合理、防止漏洞、组合权重、稀疏 vs 稠密。理解奖励如何决定策略行为。

查看完整教案 Bilibili 视频

奖励设计六大原则

原则说明反例
目标一致奖励必须与任务目标一致奖励速度但目标是稳定性
信号密度提供足够的中间信号只有到达终点的稀疏奖励
尺度合理奖励幅度应在合适范围某项奖励 1000，其他 0.1
防止漏洞避免奖励作弊路径原地旋转获得高速度奖励
组合权重各项奖励的权重需平衡所有项权重相同
稀疏/稠密根据任务选择合适密度简单任务用过度稠密奖励

Franka 奖励结构

reward = (
    1.0 * reach_reward                    # 接近奖励
    + 10 * lifted * (hand_cube_dist < 0.05)  # 提升奖励
    + 100 * command_progress * lifted     # 进度奖励
    + 20 * command_tracking_reward        # 目标跟踪
    + 220 * command_reaching_reward     # 到达奖励
    - action_penalty * action_diff_sq     # 动作平滑惩罚

训练流程：从 train.py 到模型保存

查看完整教案 Bilibili 视频

训练流程图

text
CLI 解析 (argparse)
  -> 确定 env_name = "cartpole"
  -> 加载 RLCfg (默认配置 + 命令行覆盖)
  -> 通过注册表找到 EnvCfg
  -> 创建 Env (根据 EnvCfg 参数)
  -> SKRL 包装 (VecEnv 等)
  -> 构建 Agent (PPO 等算法)
  -> 创建 Trainer
  -> trainer.train() 执行训练循环
  -> 定期保存模型 checkpoint
  -> 训练结束，保存最终模型

TensorBoard 分析要点

  • episode_reward_mean：平均奖励，应随训练逐步上升
  • episode_length_mean：平均 episode 长度，反映存活能力
  • policy_loss：策略损失，应逐渐收敛
  • value_loss：价值损失，应逐渐收敛

注册系统：新环境如何接入框架
30 分钟 注册 核心

课程概述

掌握新环境接入框架的方法：@registry.envcfg、@registry.env、@rlcfg 装饰器。理解 import 链修改与三处字符串一致性要求。

查看完整教案 Bilibili 视频

注册装饰器

python
@registry.envcfg("my_env")
@dataclass
class MyEnvCfg(EnvCfg):
    model_file: str = "my_env.xml"
    max_episode_steps: int = 500

@registry.env("my_env", "np")
class MyEnv(NpEnv):
    def __init__(self, cfg: MyEnvCfg): ...

@rlcfg("my_env")
class MyEnvPPO(PPOCfg):
    learning_rate: float = 3e-4

三处字符串必须一致

@registry.envcfg("my_env")、@registry.env("my_env", "np")、@rlcfg("my_env") 三处必须相同。train.py 中 --env my_env 会按此名字查找。

查看完整教案 Bilibili 视频

修改 Demo 的步骤

  1. 复制：复制现有 Demo 的 cfg.py 和 env.py
  2. 改名：修改类名和注册名，避免冲突
  3. 改配置：调整 EnvCfg 中的参数
  4. 改奖励：修改 _compute_reward 方法
  5. 注册：添加 @envcfg、@env、@rlcfg 装饰器
  6. 导入：在 __init__.py 中导入新模块
  7. 训练：python train.py --env 新名字
